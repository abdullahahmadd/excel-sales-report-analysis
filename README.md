## Overview

This project transforms raw sales data into a clear, structured, and professional Excel report, built to support business users in reviewing sales performance, comparing regional results, and understanding trends through organized tables, summaries, and visualizations. It was developed as a portfolio project focused on practical Excel skills for business reporting.

---

## Business Task

The objective was to transform raw sales data into a structured Excel report that helps business users review performance, compare regions, and understand trends without needing to interpret raw transactional data directly.

---

## Objectives

- Structure raw sales transaction data into clean, usable Excel tables
- Apply formulas to calculate targets, commissions, and performance logic
- Build region-specific views to support focused sales analysis
- Enable interactive exploration through pivot tables, slicers, and filters
- Present findings in a navigable, presentation-ready report format

## Methodology

**1. Data Structuring**
Organized raw sales data into structured Excel tables to support consistent formulas and reporting downstream.

**2. Logic & Formatting**
Applied sorting, formatting, and target/commission logic using IF, SUMIF, and text functions.

**3. Regional Analysis**
Created region-specific sales sheets to support focused, comparable analysis across territories.

**4. Summary Visualization**
Built a summary chart using static aggregated values to give a quick performance overview.

**5. Pivot Table Analysis**
Developed a pivot table for monthly sales analysis, enabling flexible breakdowns by time period.

**6. Interactive Exploration**
Added slicers and filters so users can explore the data by region, payment type, and other dimensions without editing formulas.

**7. Report Presentation**
Designed a cover sheet for navigation and presentation, giving the report a clear entry point.

**8. External Data Integration**
Imported and transformed external staff data to enrich the sales dataset with employee-level context.

---

## Key Findings

- Sales performance varies meaningfully across regions, with some regions contributing a disproportionately larger share of overall results.
- Monthly sales totals fluctuate across the year, highlighting distinct periods of stronger and weaker activity.
- Commission is only generated when sales meet defined targets, reinforcing the role of performance thresholds in compensation.
- Sales contributions are uneven across employees, with top performers accounting for a larger share of total sales.
- Filtering by payment type and region surfaces additional patterns in sales behavior not visible in the aggregate totals.
